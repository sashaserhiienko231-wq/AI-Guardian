# Changelog

## 2.0.0

- Unknown QR content now returns UNKNOWN instead of SAFE.
- Added dangerous-scheme and sensitive-data QR checks.
- Added Flutter live camera, camera switch, flashlight, and image fallback support.
- Added URL IP, Punycode, Unicode, suspicious port, keyword, and redirect indicators.
- Added URL feature extraction for an external real ML classifier.
- Added local, Ollama, and OpenAI provider abstraction.
- Added history search, sorting, CSV/JSON export endpoints.
- Added migration and index setup for scan history.
