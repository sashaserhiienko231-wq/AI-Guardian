# API Documentation

Interactive documentation is available at `/docs` when the backend is running.

Core endpoints:

- `GET /api/v1/health`
- `POST /api/v1/scanner/url`
- `POST /api/v1/scanner/email`
- `POST /api/v1/scanner/qr`
- `POST /api/v1/scanner/password`
- `GET /api/v1/history`
- `GET /api/v1/history/{scan_id}`
- `DELETE /api/v1/history/{scan_id}`
- `GET /api/v1/dashboard/statistics`
- `POST /api/v1/assistant/chat`
- `GET /api/v1/learning/lessons`
- `GET /api/v1/learning/progress`
- `GET /api/v1/settings`
